# 研究重点

日期：2026-11-04。

## 问题

现有模型主要在人和小鼠的功能基因组轨道上训练。目标是一个集合预测器，读取猪 DNA 序列，预测肝脏优先的分子表型：表达、染色质可及性、组蛋白修饰，随后才是剪接和翻译。

## 重点 1：先复现跨物种零样本，再谈微调

Maillard 等已经在 FAANG 的猪数据上衡量了人鼠模型。猪 H3K4me3 的最好 AUPRC 为 0.765 ± 0.009，Enformer 整体高于 DeepSEA，非保守序列也有信号。DeepGCF 说明人猪之间存在可学习的功能保守，但它的输出是保守分数。

因此第一项研究是缩小范围的复现：在猪 1–18、X、Y 号染色体上，用 Enformer 的人轨道预测 H3K4me3 或 ATAC，对 FAANG 峰计算 AUPRC 和 AUROC。全基因组 196 kb 滑窗会占满一张 A100 很长时间，第一版只抽每个染色体的固定窗口子集。

通过标准：猪 H3K4me3 的 AUPRC 达到文献报告的同一量级。明显低于 0.765 时，先查染色体命名、峰定义和轨道选择，不开始微调。

## 重点 2：只训练猪的新输出头

Borzoi 的转移教程把 trunk 冻结，换掉最后的 dense head，用新物种或新实验的 w5 轨道训练。输入长度、损失和 bin 统计都保持原模型。这是本机已有代码里唯一一条和猪微调直接对应的路径。

新头的第一批轨道只放肝脏：

- 可及性：ATAC 或 DNase
- 启动子和增强子组蛋白：H3K4me3、H3K27ac
- 表达：有链信息时使用 PigGTEx 或自有 RNA-seq 的覆盖

自有肝脏 ATAC 目前还停在比对，没有稳定的峰和覆盖轨道。轨道文件不存在时，不训练。

## 重点 3：AlphaGenome 只做人鼠对照

AlphaGenome 同时预测表达、起始、可及性、组蛋白、转录因子、染色质接触和剪接，人和小鼠轨道数量不同。模型吃物种身份。猪没有这个身份。

使用方式限于：取人猪或鼠猪直系同源区间，在人序列和鼠序列上取 AlphaGenome 分数，再和猪实验峰比较。把猪序列配上人的物种标记会得到无法解释的分数，不做。

## 重点 4：晚融合，形成一个集合

集合名称是 PigPhenotypeEnsemble。一次预测返回三组数：

- `enformer_pig`：猪序列上的零样本轨道
- `borzoi_pig_head`：猪轨道头。头未训练时该组为空
- `alphagenome_ortholog`：直系同源的人鼠对照

融合发生在评价层。同一个峰或同一个基因上，对各组分数做秩次平均。某一组缺失时，只用已有组。权重平均要等各组在同一留出染色体上算出误差后再定，不事先指定。

不生成一个合并后的权重文件。

## 重点 5：评价和停止

留出染色体使用猪的 18 号和 X 染色体，训练和零样本调参不看这两条。指标：

- 峰分类：AUPRC、AUROC
- 基因表达：预测覆盖与观测覆盖的 Spearman
- 对照：同一窗口的 DeepSEA 分数，以及直系同源区间的 AlphaGenome 分数

新头只有在留出染色体上超过冻结 Enformer，才进入集合的默认输出。没有超过，集合保持 Enformer 零样本。

## 不做的事

- 不从随机初始化训练一个新的基因组基础模型。
- 不把自监督语言模型的嵌入当作第一版表型。
- 不占用多张 GPU，也不在已有作业的卡上启动长训练。
- 不把参考基因组、测序数据和模型权重推到 GitHub。
